# Figures

This folder holds the data files behind each figure and, once made, the figures themselves. The system never writes here. The display-item plan, with the caption for each item, is in `../../Thinking-space/figures.json`.

None of the data files below exist in the example. They are listed so you can see what a real workspace would contain.

| Item | Planned data file | Contents |
|---|---|---|
| Figure 1 (overview) | none, drawn by hand | study design schematic from report to registry field |
| Figure 2 (flow) | `fig2_flow_counts.csv` | report counts at each inclusion and exclusion step, by centre |
| Figure 3 (primary result) | `fig3_accuracy_by_lesion.csv` | accuracy with bootstrap 95% CI per lesion, system and centre |
| Supplementary Table 1 | `tableS1_error_examples.csv` | one anonymised example sentence per error category, with counts |

If you place these files here, `/scifi-figures` offers to generate the figures with a script under `Thinking-space/figures/`.
